Ad Kit Details

Ad copy is generated per platform, sized to each site's practical character limit, with a Copy button — paste it directly into that platform's job posting form. (Earlier drafts of this tool included a "Post directly" / API-relay feature; it's been left out here since it required storing OAuth tokens and a self-hosted relay server that most teams don't have running — copy/paste is simpler and safer to ship as a standalone tool.)

Candidate Resume(s) * (one or more — add extra candidates to rank them)

This scores keyword overlap only — it's a fast triage/screening signal, not a hiring decision. Add one candidate for a detailed single view, or several to get a ranked leaderboard with a % match per person — like a lightweight ATS screen. The shared Key Skills field above (Role Basics) is treated as "must-have" and weighted higher; everything else is auto-extracted from the job description text. PDF/DOCX parsing runs in your browser via a small library loaded on demand — if it can't load (offline, blocked network), paste the text in directly instead. Nothing you paste or upload here is sent anywhere; it's processed entirely in this page.
